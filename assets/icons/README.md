# 界面图标来源

`plugs`、`plugs-connected`、`gear-six`、`file-arrow-up`、`sun`、`moon` 六个图标取自 [Phosphor Icons](https://github.com/phosphor-icons/core) 的 Regular SVG。原始 SVG 与本地生成的透明 PNG 一并保留。图标遵循 MIT 许可，全文见 [LICENSE.phosphor](LICENSE.phosphor)。

Windows 上可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render-ui-icons.ps1` 重新生成 PNG。客户端仅嵌入六张小图，不加载完整图标字体。
