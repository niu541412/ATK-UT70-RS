# UT70 仪表界面编号

应用模式使用 `0x03` 查询或切换界面。查询载荷为 `00 00 00 00`，切换载荷为 `编号 01 01 01`；完整发送帧见 [指令速查表](UT70%20指令速查表.md)。回复载荷首字节是仪表报告的编号。仪表按键切换时也可能主动上报，客户端会同步下拉框。

| 编号 | 界面 | 已知行为与客户端处理 |
| ---: | --- | --- |
| 0 | 基本测量 | 可远程切换 |
| 1 | 波形显示 | 可远程切换；版本查询可能超时，测量仍持续 |
| 2 | 数据记录 | 可发送切换指令；附属功能未验证 |
| 3 | 功能应用 | 可发送切换指令；附属功能未验证 |
| 4 | 手动触发 | 有状态操作；发送后以仪表显示为准 |
| 5 | 自动检测 | 可能与供电端握手并改变电压；客户端要求先确认已移除负载 |
| 11 | 监控模式 | 可发送切换指令；具体行为未验证 |
| 18 | 线阻模式 | 可远程进入；Windows 曾在切换后出现 USB 异常，客户端不等待后续查询 |
| 19 | DASH 检测 | 可发送切换指令；检测结果未验证 |
| 20 | E-Marker 检测 | 远程切换曾导致白屏或重启；客户端在发送前弹出警告 |
| 21 | E-Marker 结果页 | 只读上报；远程切换未成功，客户端显示为“其他” |
| 29 | 设置 | 可发送切换指令；附属功能未验证 |
| 255 | 其他 | 下拉框占位项，不发送切换指令 |

**即时回读只代表仪表当时报告的编号**，不能证明检测完成或界面持续稳定。E-Marker 结果页 `21` 可通过仪表按键进入并由 `GetDevUI()` 查询到，但远程发送 `20` 曾白屏或重启，发送 `21` 也未能进入结果页。被动 HID 监听未得到可确认的线缆详情帧，因此客户端不解析 E-Marker 参数。仪表上报未列出的编号时，客户端保留原始编号并在下拉框显示“其他”。
